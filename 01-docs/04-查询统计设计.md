## 统计 1 · 工作台 KPI（overview）

- **名称**：工作台 KPI 概览
- **业务含义**：首页顶部关键经营指标，反映当日/当月经营与库存健康度、待办压力。
- **输入参数**：无
- **MySQL SQL**：

```sql
-- 1) 今日销售额/单数
SELECT COUNT(*) AS todayOrders,
       IFNULL(SUM(pay_amount),0) AS todayAmount
FROM psi_stock_out_order
WHERE status='OUTSTOCK' AND DATE(create_time)=CURDATE();

-- 2) 本月销售额
SELECT IFNULL(SUM(pay_amount),0) AS monthAmount
FROM psi_stock_out_order
WHERE status='OUTSTOCK'
  AND DATE_FORMAT(create_time,'%Y-%m')=DATE_FORMAT(CURDATE(),'%Y-%m');

-- 3) 库存总额与 SKU
SELECT IFNULL(SUM(quantity*avg_cost),0) AS stockAmount,
       COUNT(DISTINCT book_id) AS totalSku
FROM psi_stock;

-- 4) 低库存预警数
SELECT COUNT(*) AS warningCount
FROM psi_stock WHERE quantity < safety_stock;

-- 5) 待处理单（草稿/已提交进货 + 已提交出货）
SELECT
 (SELECT COUNT(*) FROM psi_stock_in_order WHERE status IN ('DRAFT','SUBMITTED')) AS pendingIn,
 (SELECT COUNT(*) FROM psi_stock_out_order WHERE status='SUBMITTED') AS pendingOut;
```

- **输出字段**：`todayOrders, todayAmount, monthAmount, stockAmount, totalSku, warningCount, pendingIn, pendingOut`
- **展示方式**：指标卡片（数字 + 环比可选）

## 统计 2 · 销售趋势（sales/trend）

- **名称**：销售趋势
- **业务含义**：近 N 天每日销售额与销量，观察趋势与波动。
- **输入参数**：`days`（默认 30）
- **MySQL SQL**：

```sql
SELECT DATE(create_time) AS date,
       IFNULL(SUM(pay_amount),0) AS amount,
       IFNULL(SUM(total_qty),0)  AS qty
FROM psi_stock_out_order
WHERE status='OUTSTOCK'
  AND create_time >= DATE_SUB(CURDATE(), INTERVAL #{days} DAY)
GROUP BY DATE(create_time)
ORDER BY date;
```

- **输出字段**：`date, amount, qty`
- **展示方式**：折线图（金额）+ 柱状（数量）双轴

## 统计 3 · 月度销售（sales/monthly）

- **名称**：月度销售
- **业务含义**：指定年份逐月销售额，用于年度经营对比。

```sql
FROM psi_stock_out_order
WHERE status='OUTSTOCK' AND YEAR(create_time)=#{year}
```

- **业务含义**：按销量排序的热销图书，指导补货与陈列。
- **输入参数**：`limit`（默认 10）、`startDate`、`endDate`
- **MySQL SQL**：

```sql

       SUM(i.quantity) AS qty,

GROUP BY i.book_id, i.book_name, i.isbn
```

- **输出字段**：`bookId, bookName, isbn, qty, amount`

## 统计 15 · 库存周转率（stock/turnover）

- **名称**：库存周转率
- **业务含义**：周转率 = 期间销售成本 / 平均库存金额，衡量库存效率。
- **输入参数**：`startDate`、`endDate`
- **MySQL SQL**：

```sql
-- 分子：期间销售成本（出库成本合计）
SELECT b.id AS bookId, b.book_name AS bookName,
       IFNULL(SUM(i.quantity*i.cost_price),0) AS saleCost,
       IFNULL((SELECT SUM(s.quantity*s.avg_cost) FROM psi_stock s WHERE s.book_id=b.id),0) AS avgStockAmount,
       ROUND(
         IFNULL(SUM(i.quantity*i.cost_price),0) /
         NULLIF((SELECT SUM(s.quantity*s.avg_cost) FROM psi_stock s WHERE s.book_id=b.id),0), 2
       ) AS turnover
FROM psi_stock_out_item i
JOIN psi_stock_out_order o ON o.id=i.order_id AND o.status='OUTSTOCK'
JOIN base_book b ON b.id=i.book_id
WHERE o.create_time BETWEEN #{startDate} AND #{endDate}
GROUP BY b.id, b.book_name
ORDER BY turnover DESC;
```

- **输出字段**：`bookId, bookName, saleCost, avgStockAmount, turnover`
- **展示方式**：柱状图（周转率）/ 表格

## 统计 16 · 库龄分析（stock/age）

- **名称**：库龄分析
- **业务含义**：按最后入库时间划分库龄区间（0-30/31-90/91-180/180+ 天），识别滞销积压。
- **输入参数**：无
- **MySQL SQL**：

```sql
SELECT grp AS `range`,
       COUNT(*) AS skuCount,
       IFNULL(SUM(amount),0) AS amount
FROM (
  SELECT s.book_id,
         CASE
           WHEN DATEDIFF(CURDATE(), IFNULL(s.last_in_time, NOW())) <= 30  THEN '0-30天'
           WHEN DATEDIFF(CURDATE(), IFNULL(s.last_in_time, NOW())) <= 90  THEN '31-90天'
           WHEN DATEDIFF(CURDATE(), IFNULL(s.last_in_time, NOW())) <= 180 THEN '91-180天'
           ELSE '180天以上'
         END AS grp,
         s.quantity*s.avg_cost AS amount
  FROM psi_stock s
  WHERE s.quantity > 0
) t
GROUP BY grp
ORDER BY FIELD(grp,'0-30天','31-90天','91-180天','180天以上');
```

- **输出字段**：`range, skuCount, amount`
- **展示方式**：柱状图

## 统计 17 · 单品毛利排行（profit/by-book）

- **名称**：单品毛利排行
- **业务含义**：毛利 = (售价 - 成本)×数量，识别高毛利图书。
- **输入参数**：`limit`（默认 10）、`startDate`、`endDate`
- **MySQL SQL**：

```sql
SELECT i.book_id AS bookId, i.book_name AS bookName, i.isbn,
       IFNULL(SUM((i.price - i.cost_price)*i.quantity),0) AS profit,
       IFNULL(SUM(i.amount),0) AS amount,
       ROUND(IFNULL(SUM((i.price-i.cost_price)*i.quantity),0) /
             NULLIF(SUM(i.amount),0)*100,2) AS profitRate
FROM psi_stock_out_item i
JOIN psi_stock_out_order o ON o.id=i.order_id AND o.status='OUTSTOCK'
WHERE o.create_time BETWEEN #{startDate} AND #{endDate}
GROUP BY i.book_id, i.book_name, i.isbn
ORDER BY profit DESC
LIMIT #{limit};
```

- **输出字段**：`bookId, bookName, isbn, profit, amount, profitRate`
- **展示方式**：柱状图 / 表格

- **输出字段**：`month, profit, amount, profitRate`
- **展示方式**：折线/柱状图

## 统计 20 · 活跃会员与复购率（customer/active）

- **名称**：活跃会员数 / 复购率
- **业务含义**：近 N 天有消费的会员数与复购率（消费≥2次会员占比）。
- **输入参数**：`days`（默认 30）
- **MySQL SQL**：

```sql
SELECT COUNT(*) AS activeMembers,
       SUM(CASE WHEN cnt>=2 THEN 1 ELSE 0 END) AS repeatMembers,
       ROUND(SUM(CASE WHEN cnt>=2 THEN 1 ELSE 0 END)/NULLIF(COUNT(*),0)*100,2) AS repeatRate,
       IFNULL(AVG(amt),0) AS avgAmount
FROM (
  SELECT o.customer_id, COUNT(*) AS cnt, SUM(o.pay_amount) AS amt
  FROM psi_stock_out_order o
  JOIN base_customer c ON c.id=o.customer_id AND c.customer_type='MEMBER'
  WHERE o.status='OUTSTOCK'
    AND o.create_time >= DATE_SUB(CURDATE(), INTERVAL #{days} DAY)
  GROUP BY o.customer_id
) t;
```

- **输出字段**：`activeMembers, repeatMembers, repeatRate, avgAmount`
- **展示方式**：卡片（会员数/复购率）+ 折线（趋势可扩展）

## 统计 22 · 盘点差异汇总（check/diff-summary）

- **名称**：盘点差异汇总
- **业务含义**：期间盘点单的差异品种、盘盈盘亏汇总，评估库存准确性。
- **输入参数**：`startDate`、`endDate`
- **MySQL SQL**：

```sql
SELECT o.check_no AS checkNo, w.warehouse_name AS warehouseName,
       o.check_type AS checkType,
       o.total_items AS totalItems, o.diff_items AS diffItems,
       o.profit_qty AS profitQty, o.loss_qty AS lossQty,
       o.finish_time AS finishTime
FROM psi_stock_check_order o
LEFT JOIN base_warehouse w ON w.id=o.warehouse_id
WHERE o.status='FINISHED'
  AND o.create_time BETWEEN #{startDate} AND #{endDate}
ORDER BY o.create_time DESC;

-- 期间汇总
SELECT COUNT(*) AS checkCount,
       SUM(total_items) AS totalItems,
       SUM(diff_items) AS diffItems,
       SUM(profit_qty) AS profitQty,
       SUM(loss_qty) AS lossQty
FROM psi_stock_check_order
WHERE status='FINISHED'
  AND create_time BETWEEN #{startDate} AND #{endDate};
```

- **输出字段**：`checkNo, warehouseName, checkType, totalItems, diffItems, profitQty, lossQty, finishTime`（明细）+ 汇总 `checkCount, totalItems, diffItems, profitQty, lossQty`
- **展示方式**：表格 + 汇总柱状图

## 附：统计实现约定

| 约定 | 说明 |
|---|---|
| 状态口径 | 销售类统计仅取 `status='OUTSTOCK'`；采购类仅取 `status='INSTOCK'` |
| 时间口径 | 默认取 `create_time`；如需出/入库实际时间可取 `out_time/in_time` |
| 成本口径 | 出库成本取明细 `cost_price`（出库时固化的移动加权平均成本） |
| 库龄口径 | 基于 `psi_stock.last_in_time`，无值按当前时间处理 |
| 性能 | 大表（`psi_stock_flow`/明细表）按 `create_time`、`book_id` 建索引；统计可加缓存或汇总表 |
| 信创 | `DATE_FORMAT/DATE_SUB/IFNULL/FIELD` 在达梦/openGauss 需替换或使用函数适配层，见 [10-信创适配方案](10-信创适配方案.md) |
