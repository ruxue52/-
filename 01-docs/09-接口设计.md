# 09 · 接口设计（REST API 契约 · 权威版本）

> 本文件是所有端（B/S、PC、APP、小程序）与后端联调的**唯一权威契约**。
> 后端实现、前端调用、文档描述均以本文件为准。数据库结构见 `02-database/schema.sql`。

## 1. 通用约定

| 项 | 约定 |
|---|---|
| 基础路径 | `/api` |
| 数据格式 | JSON（UTF-8），请求/响应 `Content-Type: application/json` |
| 认证方式 | JWT，请求头 `Authorization: Bearer <token>` |
| 分页参数 | `page`（从 1 开始，默认 1）、`size`（默认 10，最大 200） |
| 排序参数 | `sort`（如 `createTime,desc`） |
| 成功响应 | `{ "code": 0, "message": "ok", "data": {...} }` |
| 分页响应 | `{ "code":0, "message":"ok", "data": { "total": 123, "page":1, "size":10, "records":[...] } }` |
| 业务错误 | `{ "code": 1001, "message": "库存不足", "data": null }` |
| 未认证 | HTTP 401，`{ "code": 401, "message": "未登录或登录已过期" }` |
| 无权限 | HTTP 403，`{ "code": 403, "message": "无访问权限" }` |
| 服务异常 | HTTP 500，`{ "code": 500, "message": "系统异常" }` |
| 时间格式 | `yyyy-MM-dd HH:mm:ss`（日期 `yyyy-MM-dd`） |
| 金额 | 字符串或数字，保留 2 位小数 |
| 单号规则 | 进货 `PI` + `yyyyMMdd` + 3 位流水；出货 `SO`…；盘点 `CK`…；调拨 `TR`…；退货 `RT`… |

### 错误码表

| code | 含义 |
|---|---|
| 0 | 成功 |
| 1001 | 参数校验失败 |
| 1002 | 库存不足 |
| 1003 | 单据状态不允许该操作 |
| 1004 | 数据不存在 |
| 1005 | 数据重复（如 ISBN 已存在） |
| 2001 | 账号或密码错误 |
| 2002 | 账号被停用 |
| 3001 | 无权限 |

## 2. 认证与用户

### 2.1 登录
`POST /api/auth/login`
```json
// 请求
{ "username": "admin", "password": "123456" }
// 响应 data
{
  "token": "eyJhbGciOi...",
  "userInfo": { "id":1, "username":"admin", "realName":"系统管理员", "roles":["ADMIN"] },
  "permissions": ["base:book","purchase:in", "..."]
}
```

### 2.2 当前用户
`GET /api/auth/me` → `data`: `{ id, username, realName, phone, email, roles:[], permissions:[] }`

### 2.3 退出
`POST /api/auth/logout` → `data: null`

## 12. 读者端（会员端，面向顾客）

读者端（`09-customer-miniprogram`）接口统一前缀 `/api/reader`，与员工端完全分离。

**身份与鉴权**：JWT 载荷新增 `userType`；员工 `STAFF`（可访问全部接口），会员 `CUSTOMER`（**仅**可访问 `/api/reader/**`，访问其它接口返回 403）。会员登录不校验密码，采用「手机号 + 短信验证码」，手机号须与 `base_customer.phone` 匹配且在册。

**字段脱敏**：读者端不返回 `purchasePrice` / `avgCost` / `costPrice` 等内部成本字段。

### 12.1 公开接口（免登录）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/reader/books` | 图书检索：`page`、`size`、`keyword`（书名/作者/ISBN）、`categoryId`（含其子分类）、`sort`（`newest` 按上架倒序，缺省按 id 升序）；仅返回在售图书 |
| GET | `/api/reader/books/{id}` | 图书详情 → `{book, stock:[{warehouseId,warehouseName,quantity}], totalQuantity, available}` |
| GET | `/api/reader/books/by-isbn/{isbn}` | 扫码 / 手输 ISBN 查书，结构同上；图书已下架或不存在返回 `1004` |
| GET | `/api/reader/categories` | 图书分类树（仅启用分类） |
| GET | `/api/reader/levels` | 会员等级与权益（`discount` 结算价百分比、`pointRate` 积分倍率） |
| POST | `/api/reader/auth/send-code` | body `{phone}` → `{phone, expireMinutes, code}`；未注册手机号返回 `1004` |
| POST | `/api/reader/auth/login` | body `{phone, code}` → `{token, member}`；验证码错误/过期返回 `2001` |

> 演示环境未接短信网关，`send-code` 会在 `data.code` 回显 6 位验证码（由 `reader.auth.echo-code` 开关控制，接入网关后置为 `false`）。

### 12.2 会员接口（需 `CUSTOMER` 身份 token）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/reader/member/profile` | 会员资料 + 消费汇总：`id, customerCode, customerName, phone, levelCode, levelName, discount, pointRate, points, balance, orderCount, totalAmount` |
| GET | `/api/reader/member/orders` | 我的消费记录（已出库单据，按时间倒序，分页） |
| GET | `/api/reader/member/orders/{id}` | 消费明细 → `{order, items:[{bookId,bookName,isbn,quantity,price,amount}]}`；非本人单据返回 `3001` |

示例：
```json
// POST /api/reader/auth/login 响应 data
{ "token": "eyJhbGciOi...", "member": { "id":3, "customerCode":"C0003", "customerName":"李娜",
  "levelName":"银卡会员", "discount":95, "pointRate":2, "points":860, "balance":50.00 } }
```
