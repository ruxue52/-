# 05 · 报表设计（15 张）

> 本章设计 **15 张报表（R01~R15）**，对应 [09-接口设计 §9](09-接口设计.md)。统一接口 `GET /api/report/{code}` 返回 `{title, columns:[{key,label}], rows:[...], summary:{...}}`；导出 `GET /api/report/{code}/export?format=xlsx|csv`。
> 报表统一以 `psi_stock_out_order/item`、`psi_stock_in_order/item`、`psi_stock`、`psi_stock_flow`、`psi_stock_check_*`、`base_*` 为数据来源，字段与 `schema.sql` 一致。

## R01 · 销售日报表

- **名称**：销售日报表
- **用途**：按日汇总当日销售明细与销售总额，供门店日结与对账。
- **数据来源表**：`psi_stock_out_order`、`psi_stock_out_item`、`base_book`、`base_warehouse`
- **参数**：`date`（日期，必填）
- **列定义**：

| 列 key | 显示名 | 说明 |
|---|---|---|
| orderNo | 单号 | `SO...` |
| outTime | 出库时间 | `out_time` |
| bookName | 书名 | 快照 |
| isbn | ISBN | 快照 |
| quantity | 数量 | 明细 |
| price | 单价 | 明细 |
| amount | 金额 | 明细 |
| costPrice | 成本单价 | 明细 |
| paymentType | 支付方式 | 单头 |
| operatorName | 收银员 | 单头 |

- **汇总项**：单据数、总数量、销售总额、总成本、毛利额
- **展示与导出**：表格展示，支持 Excel/CSV 导出；小票式可选打印。
- **SQL 示例**：

```sql
SELECT o.order_no, o.out_time, i.book_name, i.isbn, i.quantity, i.price, i.amount,
       i.cost_price, o.payment_type, o.operator_name
FROM psi_stock_out_order o
JOIN psi_stock_out_item i ON i.order_id=o.id
WHERE o.status='OUTSTOCK' AND DATE(o.create_time)=#{date}
ORDER BY o.out_time;
```

## R02 · 销售月报表

- **名称**：销售月报表
- **用途**：按月汇总每日销售额/毛利，月度经营分析。
- **数据来源表**：`psi_stock_out_order`、`psi_stock_out_item`
- **参数**：`month`（如 `2026-09`）
- **列定义**：

| 列 key | 显示名 |
|---|---|
| date | 日期 |
| orders | 单数 |
| qty | 销量 |
| amount | 销售额 |
| cost | 销售成本 |
| profit | 毛利 |
| profitRate | 毛利率(%) |

- **汇总项**：月度合计（单数/销量/销售额/成本/毛利/毛利率）
- **展示与导出**：表格 + 折线图，支持导出。
- **SQL 示例**：

```sql
SELECT DATE(o.create_time) AS date, COUNT(DISTINCT o.id) AS orders,
       SUM(i.quantity) AS qty, SUM(i.amount) AS amount,
       SUM(i.quantity*i.cost_price) AS cost,
       SUM((i.price-i.cost_price)*i.quantity) AS profit
FROM psi_stock_out_order o
JOIN psi_stock_out_item i ON i.order_id=o.id
WHERE o.status='OUTSTOCK' AND DATE_FORMAT(o.create_time,'%Y-%m')=#{month}
GROUP BY DATE(o.create_time) ORDER BY date;
```

## R03 · 商品销售排行榜

- **名称**：商品销售排行榜
- **用途**：按销量/销售额排序的热销商品，指导补货。
- **数据来源表**：`psi_stock_out_item`、`psi_stock_out_order`、`base_book`
- **参数**：`startDate,endDate,limit`（默认 10）
- **列定义**：排名、书名、ISBN、分类、销量、销售额、毛利
- **汇总项**：TopN 合计销量/销售额
- **展示与导出**：横向柱状图 + 表格，支持导出。
- **SQL 示例**：见 [04-查询统计设计 统计 4](04-查询统计设计.md)。

## R04 · 分类销售汇总表

- **名称**：分类销售汇总表
- **用途**：各分类销售金额/数量汇总，优化品类结构。
- **数据来源表**：`psi_stock_out_item`、`base_book`、`base_category`
- **参数**：`startDate,endDate`
- **列定义**：分类名称、销售数量、销售额、占比(%)、毛利
- **汇总项**：全部合计
- **展示与导出**：表格 + 饼图，支持导出。
- **SQL 示例**：

```sql
SELECT c.category_name,
       SUM(i.quantity) AS qty, SUM(i.amount) AS amount,
       SUM((i.price-i.cost_price)*i.quantity) AS profit
FROM psi_stock_out_item i
JOIN psi_stock_out_order o ON o.id=i.order_id AND o.status='OUTSTOCK'
JOIN base_book b ON b.id=i.book_id
LEFT JOIN base_category c ON c.id=b.category_id
WHERE o.create_time BETWEEN #{startDate} AND #{endDate}
GROUP BY c.category_name ORDER BY amount DESC;
```

## R05 · 采购到货明细表

- **名称**：采购到货明细表
- **用途**：按供应商与时间列出进货到货明细，供采购对账。
- **数据来源表**：`psi_stock_in_order`、`psi_stock_in_item`、`base_supplier`、`base_warehouse`
- **参数**：`startDate,endDate,supplierId`
- **列定义**：单号、到货时间、供应商、仓库、书名、ISBN、数量、单价、金额、结算方式
- **汇总项**：单据数、采购数量、采购金额、已付金额
- **展示与导出**：表格，支持导出。
- **SQL 示例**：

```sql
SELECT o.order_no, o.in_time, s.supplier_name, w.warehouse_name,
       i.book_name, i.isbn, i.quantity, i.price, i.amount, o.settle_type, o.paid_amount
FROM psi_stock_in_order o
JOIN psi_stock_in_item i ON i.order_id=o.id
LEFT JOIN base_supplier s ON s.id=o.supplier_id
LEFT JOIN base_warehouse w ON w.id=o.warehouse_id
WHERE o.status='INSTOCK'
  AND o.create_time BETWEEN #{startDate} AND #{endDate}
  AND (#{supplierId} IS NULL OR o.supplier_id=#{supplierId})
ORDER BY o.in_time;
```

## R06 · 供应商采购汇总表

- **名称**：供应商采购汇总表
- **用途**：各供应商采购金额/单量/付款情况汇总。
- **数据来源表**：`psi_stock_in_order`、`base_supplier`
- **参数**：`startDate,endDate`
- **列定义**：供应商、单数、采购金额、已付金额、未付金额、占比(%)
- **汇总项**：全部合计
- **展示与导出**：表格 + 饼图，支持导出。
- **SQL 示例**：

```sql
SELECT s.supplier_name, COUNT(o.id) AS orders,
       IFNULL(SUM(o.pay_amount),0) AS amount,
       IFNULL(SUM(o.paid_amount),0) AS paid,
       IFNULL(SUM(o.pay_amount-o.paid_amount),0) AS unpaid
FROM psi_stock_in_order o
LEFT JOIN base_supplier s ON s.id=o.supplier_id
WHERE o.status='INSTOCK' AND o.create_time BETWEEN #{startDate} AND #{endDate}
GROUP BY s.supplier_name ORDER BY amount DESC;
```

## R07 · 库存结存表

- **名称**：库存结存表
- **用途**：按仓库/分类列出当前库存结存数量与金额。
- **数据来源表**：`psi_stock`、`base_book`、`base_category`、`base_warehouse`
- **参数**：`warehouseId,categoryId`
- **列定义**：仓库、分类、书名、ISBN、货架位、数量、安全库存、移动加权成本、库存金额
- **汇总项**：SKU 数、总数量、总金额
- **展示与导出**：表格，支持导出。
- **SQL 示例**：

```sql
SELECT w.warehouse_name, c.category_name, b.book_name, b.isbn, b.shelf_no,
       s.quantity, s.safety_stock, s.avg_cost,
       (s.quantity*s.avg_cost) AS stock_amount
FROM psi_stock s
JOIN base_book b ON b.id=s.book_id
LEFT JOIN base_category c ON c.id=b.category_id
LEFT JOIN base_warehouse w ON w.id=s.warehouse_id
WHERE (#{warehouseId} IS NULL OR s.warehouse_id=#{warehouseId})
  AND (#{categoryId} IS NULL OR b.category_id=#{categoryId})
ORDER BY w.warehouse_name, c.category_name, b.book_name;
```

## R08 · 库存预警表

- **名称**：库存预警表
- **用途**：列出低于安全库存的 SKU，驱动补货。
- **数据来源表**：`psi_stock`、`base_book`、`base_warehouse`
- **参数**：`warehouseId`
- **列定义**：仓库、书名、ISBN、当前数量、安全库存、缺口数量、建议补货量
- **汇总项**：预警 SKU 数、缺口总量
- **展示与导出**：表格（高亮），支持导出。
- **SQL 示例**：

```sql
SELECT w.warehouse_name, b.book_name, b.isbn,
       s.quantity, s.safety_stock,
       (s.safety_stock-s.quantity) AS gap_qty
FROM psi_stock s
JOIN base_book b ON b.id=s.book_id
LEFT JOIN base_warehouse w ON w.id=s.warehouse_id
WHERE s.quantity < s.safety_stock
  AND (#{warehouseId} IS NULL OR s.warehouse_id=#{warehouseId})
ORDER BY gap_qty DESC;
```

## R10 · 盘点差异表

- **名称**：盘点差异表
- **用途**：列示盘点单的品种差异，评估库存准确性。
- **数据来源表**：`psi_stock_check_order`、`psi_stock_check_item`、`base_warehouse`
- **参数**：`checkNo,startDate,endDate`
- **列定义**：盘点单号、仓库、盘点类型、书名、ISBN、账面数量、实盘数量、差异数量、差异金额
- **汇总项**：盘点品种数、差异品种数、盘盈数量、盘亏数量、差异金额合计
- **展示与导出**：表格，支持导出。
- **SQL 示例**：

```sql
SELECT o.check_no, w.warehouse_name, o.check_type,
       i.book_name, i.isbn, i.book_qty, i.real_qty, i.diff_qty, i.diff_amount
FROM psi_stock_check_order o
JOIN psi_stock_check_item i ON i.order_id=o.id
LEFT JOIN base_warehouse w ON w.id=o.warehouse_id
WHERE o.status='FINISHED'
  AND (#{checkNo} IS NULL OR o.check_no=#{checkNo})
  AND (#{startDate} IS NULL OR o.create_time >= #{startDate})
  AND (#{endDate} IS NULL OR o.create_time <= #{endDate})
ORDER BY o.check_no, i.diff_qty DESC;
```

## R11 · 商品毛利分析表

- **名称**：商品毛利分析表
- **用途**：按商品统计销售额、成本、毛利与毛利率。
- **数据来源表**：`psi_stock_out_item`、`psi_stock_out_order`、`base_book`
- **参数**：`startDate,endDate`
- **列定义**：书名、ISBN、销量、销售额、成本、毛利、毛利率(%)
- **汇总项**：合计销售额、成本、毛利、综合毛利率
- **展示与导出**：表格 + 柱状图，支持导出。
- **SQL 示例**：

```sql
SELECT i.book_name, i.isbn, SUM(i.quantity) AS qty,
       SUM(i.amount) AS amount,
       SUM(i.quantity*i.cost_price) AS cost,
       SUM((i.price-i.cost_price)*i.quantity) AS profit,
       ROUND(SUM((i.price-i.cost_price)*i.quantity)/NULLIF(SUM(i.amount),0)*100,2) AS profit_rate
FROM psi_stock_out_item i
JOIN psi_stock_out_order o ON o.id=i.order_id AND o.status='OUTSTOCK'
WHERE o.create_time BETWEEN #{startDate} AND #{endDate}
GROUP BY i.book_name, i.isbn ORDER BY profit DESC;
```

## R12 · 客户消费明细表

- **名称**：客户消费明细表
- **用途**：某客户在期间内的消费明细与汇总。
- **数据来源表**：`psi_stock_out_order`、`psi_stock_out_item`、`base_customer`
- **参数**：`customerId,startDate,endDate`
- **列定义**：单号、消费时间、书名、数量、金额、支付方式、累计积分
- **汇总项**：消费单数、消费金额、获得积分
- **展示与导出**：表格，支持导出。
- **SQL 示例**：

```sql
SELECT o.order_no, o.create_time, i.book_name, i.quantity, i.amount,
       o.payment_type, c.points
```

## R13 · 会员积分报表

- **名称**：会员积分报表
- **用途**：按会员等级列示会员积分与余额，支持会员运营。
- **数据来源表**：`base_customer`、`base_member_level`

- **展示与导出**：表格 + 饼图（等级分布），支持导出。

```sql
SELECT c.customer_code, c.customer_name, c.phone,
```

## R14 · 库存流水台账

- **名称**：库存流水台账
- **用途**：按图书/仓库/期间列出全部出入库流水，库存追溯核心。
- **数据来源表**：`psi_stock_flow`、`base_book`、`base_warehouse`
- **参数**：`bookId,warehouseId,startDate,endDate`
- **列定义**：时间、业务类型、业务单号、仓库、书名、ISBN、方向、变动数量、变动前、变动后、单位成本、操作人、来源
- **汇总项**：入库合计、出库合计、期末数量
- **展示与导出**：表格，支持导出。
- **SQL 示例**：

```sql
SELECT f.create_time, f.biz_type, f.biz_no, w.warehouse_name,
       b.book_name, b.isbn, f.direction, f.quantity,
       f.before_qty, f.after_qty, f.unit_cost, f.operator_name, f.source
FROM psi_stock_flow f
JOIN base_book b ON b.id=f.book_id
LEFT JOIN base_warehouse w ON w.id=f.warehouse_id
WHERE (#{bookId} IS NULL OR f.book_id=#{bookId})
  AND (#{warehouseId} IS NULL OR f.warehouse_id=#{warehouseId})
  AND (#{startDate} IS NULL OR f.create_time >= #{startDate})
  AND (#{endDate} IS NULL OR f.create_time <= #{endDate})
ORDER BY f.create_time;
```

## R15 · 进销存汇总表

- **名称**：进销存汇总表
- **用途**：按月/仓库汇总「期初 + 进货 - 出货 ± 其他 = 期末」，进销存对账。
- **数据来源表**：`psi_stock_flow`（聚合各 biz_type）、`base_warehouse`
- **参数**：`month,warehouseId`
- **列定义**：仓库、期初数量、进货入库、销售出库、调拨净额、盘点调整、退货净额、期末数量
- **汇总项**：各列合计
- **展示与导出**：表格，支持导出。
- **SQL 示例**（以流水按业务类型聚合）：

```sql
SELECT w.warehouse_name,
  SUM(CASE WHEN f.biz_type='INIT' THEN f.quantity*f.direction ELSE 0 END) AS opening,
  SUM(CASE WHEN f.biz_type='IN'   THEN f.quantity ELSE 0 END) AS purchaseIn,
  SUM(CASE WHEN f.biz_type='OUT'  THEN f.quantity ELSE 0 END) AS saleOut,
  SUM(CASE WHEN f.biz_type IN ('TRANSFER_IN','TRANSFER_OUT')
           THEN f.quantity*f.direction ELSE 0 END) AS transferNet,
  SUM(CASE WHEN f.biz_type='CHECK' THEN f.quantity*f.direction ELSE 0 END) AS checkAdj,
  SUM(CASE WHEN f.biz_type IN ('RET_PUR','RET_SAL')
           THEN f.quantity*f.direction ELSE 0 END) AS returnNet,
  SUM(f.quantity*f.direction) AS closing
FROM psi_stock_flow f
LEFT JOIN base_warehouse w ON w.id=f.warehouse_id
WHERE DATE_FORMAT(f.create_time,'%Y-%m')=#{month}
  AND (#{warehouseId} IS NULL OR f.warehouse_id=#{warehouseId})
GROUP BY w.warehouse_name;
```

## 附：报表通用约定

| 约定 | 说明 |
|---|---|
| 返回结构 | `{title, columns:[{key,label}], rows:[...], summary:{...}}` |
| 导出 | `GET /api/report/{code}/export?format=xlsx\|csv`，POI 生成；CSV 使用 UTF-8 BOM 防乱码 |
| 权限 | 报表访问需 `report` 权限；敏感报表（R11/R06 财务相关）限店长及以上 |
| 大数据量 | 超过阈值（如 5 万行）建议限制时间范围或异步导出 |
| 信创 | 导出为纯文件流，与数据库无关；SQL 需函数适配（见 [10-信创适配方案](10-信创适配方案.md)） |
| 打印 | R01 支持小票/凭证打印；R07/R08 支持 A4 打印 |
