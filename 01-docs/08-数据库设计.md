# 08 · 数据库设计

> 本章对 `02-database/schema.sql` 的 **30 张表**逐表说明：表名、中文名、用途、字段清单（类型+说明）、主键与索引、外键与关系。
> ER 图见 [03-UML图集 §3](03-UML图集.md)。字符集 `utf8mb4`；金额 `DECIMAL(14,2)`、数量 `DECIMAL(14,3)`、成本 `DECIMAL(14,4)`。

---

## 1. 设计原则

| 原则 | 说明 |
|---|---|
| 通用 SQL 子集 | 只使用悠游 MySQL/达梦/openGauss 均支持的类型与语法，便于信创迁移 |
| 统一前缀分域 | `sys_*` 系统域、`base_*` 基础数据域、`psi_*` 进销存域 |
| 统一主键 | 所有业务表 `id BIGINT AUTO_INCREMENT` 代理主键，业务唯一键用 `UNIQUE KEY` |
| 快照冗余 | 单据明细冗余 `book_name`/`isbn`，保证历史单据不受主数据变更影响 |
| 金额/数量精度 | 金额 2 位、数量 3 位、成本 4 位，全用 `DECIMAL` |
| 时间字段 | 统一 `DATETIME`；`create_time` 默认 `CURRENT_TIMESTAMP` |
| 索引策略 | 高频查询字段（状态、外键、时间、编码）建普通索引；唯一业务码建唯一索引 |
| 暂不建物理外键 | 物理脚本不使用 `FOREIGN KEY`，由应用层保证引用完整性（便于分库/迁移） |

## 2. 命名规范

| 对象 | 规范 | 示例 |
|---|---|---|
| 表名 | 域前缀 + 下划线小写 | `psi_stock_in_order` |
| 字段名 | 下划线小写 | `book_name`、`avg_cost` |
| 主键 | `id` | `id` |
| 外键字段 | `xxx_id` | `supplier_id`、`warehouse_id` |
| 唯一索引 | `uk_<字段>` | `uk_book_isbn` |
| 普通索引 | `idx_<含义>` | `idx_in_status` |
| 状态编码 | 大写下划线 | `DRAFT`、`INSTOCK` |

## 3. 字符集与精度约定

- **字符集**：MySQL `utf8mb4`（达梦使用 UTF-8）；排序规则默认。
- **金额**：`DECIMAL(14,2)`，如定价、金额、应付/实收。
- **数量**：`DECIMAL(14,3)`，支持图书按册/套/包计量。
- **成本**：`DECIMAL(14,4)`，用于移动加权平均成本与单位成本，避免累计误差。
- **折扣率**：`DECIMAL(5,2)`（如 `100` 表示不打折）。
- **时间**：`DATETIME`；日期型字符串（如出版日期 `YYYY-MM`）用 `VARCHAR(16)`。

## 4. 系统管理域（8 张）

### 4.1 `sys_role` 系统角色

- **用途**：定义角色及权限归属，RBAC 的角色维度。
- **字段**：

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | 角色ID |
| role_code | VARCHAR(64) UK | 角色编码（ADMIN/MANAGER/…） |
| role_name | VARCHAR(64) | 角色名称 |
| description | VARCHAR(255) | 描述 |
| status | TINYINT | 1启用 0停用 |
| create_time | DATETIME | 创建时间 |
| update_time | DATETIME | 更新时间 |

- **主键/索引**：PK `id`；UK `uk_role_code`。
- **关系**：`sys_user_role`、`sys_role_permission` 的关联目标。

### 4.2 `sys_user` 系统用户

- **用途**：系统登录用户。
- **字段**：`id(PK)`、`username(VARCHAR64,UK)`、`password(VARCHAR128,BCrypt)`、`real_name`、`phone`、`email`、`avatar`、`gender(TINYINT 0未知1男2女)`、`status(TINYINT)`、`last_login(DATETIME)`、`create_time`、`update_time`。
- **主键/索引**：PK `id`；UK `uk_username`。
- **关系**：与 `sys_role` 多对多（经 `sys_user_role`）；产生 `sys_operation_log`。

### 4.3 `sys_permission` 系统权限

- **用途**：菜单/按钮/API 三级权限定义。
- **字段**：`id(PK)`、`perm_code(VARCHAR128,UK,如 psi:stockIn:add)`、`perm_name`、`perm_type(VARCHAR16 MENU/BUTTON/API)`、`parent_id(BIGINT)`、`path`、`icon`、`sort_no`。
- **主键/索引**：PK `id`；UK `uk_perm_code`。
- **关系**：与 `sys_role` 多对多（经 `sys_role_permission`）；`parent_id` 自关联成树。

### 4.4 `sys_role_permission` 角色-权限

- **用途**：角色与权限的多对多关联。
- **字段**：`role_id(BIGINT)`、`permission_id(BIGINT)`。
- **主键**：复合 PK `(role_id, permission_id)`。
- **关系**：`sys_role` ↔ `sys_permission`。

### 4.5 `sys_user_role` 用户-角色

- **用途**：用户与角色的多对多关联。
- **字段**：`user_id(BIGINT)`、`role_id(BIGINT)`。
- **主键**：复合 PK `(user_id, role_id)`。
- **关系**：`sys_user` ↔ `sys_role`。

### 4.6 `sys_operation_log` 操作日志

- **用途**：关键操作审计。
- **字段**：`id(PK)`、`user_id`、`username`、`module`、`operation`、`method`、`params(VARCHAR2000)`、`ip`、`cost_ms(BIGINT)`、`success(TINYINT)`、`error_msg(VARCHAR1000)`、`create_time`。
- **主键/索引**：PK `id`；`idx_log_user(user_id)`、`idx_log_time(create_time)`。
- **关系**：归因于 `sys_user`。

### 4.7 `sys_dict` 数据字典

- **用途**：字典类型定义（单据状态、结算方式等）。
- **字段**：`id(PK)`、`dict_code(VARCHAR64,UK)`、`dict_name`、`remark`。
- **主键/索引**：PK `id`；UK `uk_dict_code`。
- **关系**：一对多 `sys_dict_item`。

### 4.8 `sys_dict_item` 字典项

- **用途**：字典明细项。
- **字段**：`id(PK)`、`dict_code`、`item_value`、`item_label`、`sort_no`、`status`。
- **主键/索引**：PK `id`；`idx_dict_item_code(dict_code)`。
- **关系**：属 `sys_dict`。

## 5. 基础数据域（8 张）

### 5.1 `base_category` 图书分类（树形）

- **用途**：图书分类，支持父子层级。
- **字段**：`id(PK)`、`parent_id(BIGINT,0为根)`、`category_name`、`category_code`、`sort_no`、`status`、`create_time`。
- **主键/索引**：PK `id`；`idx_category_parent(parent_id)`。
- **关系**：`parent_id` 自关联；被 `base_book.category_id` 引用。

### 5.2 `base_publisher` 出版社

- **字段**：`id(PK)`、`publisher_name(VARCHAR128,UK)`、`contact`、`phone`、`address`、`status`、`create_time`。
- **主键/索引**：PK `id`；UK `uk_publisher_name`。
- **关系**：被 `base_book.publisher_id` 引用。

### 5.3 `base_supplier` 供应商

- **字段**：`id(PK)`、`supplier_code(VARCHAR64,UK)`、`supplier_name`、`contact`、`phone`、`address`、`settle_type(VARCHAR32 CASH/CREDIT/PERIOD)`、`credit_limit(DECIMAL14,2)`、`status`、`create_time`。
- **主键/索引**：PK `id`；UK `uk_supplier_code`。
- **关系**：被 `psi_stock_in_order.supplier_id`、`psi_return_order.partner_id`（PURCHASE）引用。

### 5.4 `base_member_level` 会员等级

- **字段**：`id(PK)`、`level_code(VARCHAR32,UK)`、`level_name`、`discount(DECIMAL5,2,折扣率%,100不打折)`、`point_rate(DECIMAL5,2,积分倍率)`。
- **主键/索引**：PK `id`；UK `uk_level_code`。
- **关系**：被 `base_customer.level_id` 引用。

### 5.5 `base_customer` 客户/会员

- **字段**：`id(PK)`、`customer_code(VARCHAR64,UK)`、`customer_name`、`customer_type(VARCHAR16 RETAIL/WHOLESALE/MEMBER)`、`phone`、`address`、`level_id(BIGINT)`、`points(INT)`、`balance(DECIMAL14,2)`、`status`、`create_time`。
- **主键/索引**：PK `id`；UK `uk_customer_code`；`idx_customer_phone(phone)`。
- **关系**：`level_id`→`base_member_level`；被 `psi_stock_out_order.customer_id`、`psi_return_order.partner_id`（SALES）引用。

### 5.6 `base_warehouse` 仓库

- **字段**：`id(PK)`、`warehouse_code(VARCHAR64,UK)`、`warehouse_name`、`location`、`manager`、`status`、`create_time`。
- **主键/索引**：PK `id`；UK `uk_warehouse_code`。
- **关系**：被 `psi_stock.warehouse_id` 及各单据 `warehouse_id` 引用。

### 5.7 `base_book` 图书（商品）

- **用途**：图书主数据，ISBN 唯一。
- **字段**：

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | 图书ID |
| isbn | VARCHAR(32) UK | ISBN（条形码） |
| book_name | VARCHAR(255) | 书名 |
| author | VARCHAR(128) | 作者 |
| publisher_id | BIGINT | 出版社ID |
| category_id | BIGINT | 分类ID |
| publish_date | VARCHAR(16) | 出版日期(YYYY-MM) |
| price | DECIMAL(14,2) | 定价 |
| purchase_price | DECIMAL(14,2) | 参考进价 |
| sale_price | DECIMAL(14,2) | 零售价 |
| unit | VARCHAR(16) | 单位(默认"册") |
| shelf_no | VARCHAR(64) | 货架位 |
| cover_url | VARCHAR(255) | 封面图 |
| summary | VARCHAR(1000) | 简介 |
| status | TINYINT | 1在售 0停售 |
| create_time/update_time | DATETIME | 时间 |

- **主键/索引**：PK `id`；UK `uk_book_isbn`；`idx_book_name`、`idx_book_publisher`、`idx_book_category`。
- **关系**：`publisher_id`→`base_publisher`；`category_id`→`base_category`；被 `psi_stock`、各明细表引用。

### 5.8 `psi_stock` 库存（按图书+仓库）

- **用途**：库存主表，记录在库/锁定/安全库存与移动加权成本。
- **字段**：`id(PK)`、`book_id(BIGINT)`、`warehouse_id(BIGINT)`、`quantity(DECIMAL14,3在库)`、`locked_qty(DECIMAL14,3锁定)`、`safety_stock(DECIMAL14,3安全库存)`、`avg_cost(DECIMAL14,4移动加权成本)`、`last_in_time(DATETIME)`、`last_out_time(DATETIME)`、`update_time`。
- **主键/索引**：PK `id`；UK `uk_stock_book_wh(book_id,warehouse_id)`；`idx_stock_book(book_id)`。
- **关系**：`book_id`→`base_book`；`warehouse_id`→`base_warehouse`；产生 `psi_stock_flow`。

## 6. 进货域（3 张）

### 6.1 `psi_stock_in_order` 进货单

- **字段**：`id(PK)`、`order_no(VARCHAR64,UK,PI前缀)`、`supplier_id`、`warehouse_id`、`total_qty(DECIMAL14,3)`、`total_amount(DECIMAL14,2)`、`discount(DECIMAL14,2)`、`pay_amount(DECIMAL14,2)`、`paid_amount(DECIMAL14,2)`、`settle_type(VARCHAR32)`、`status(VARCHAR16 DRAFT/SUBMITTED/INSTOCK/CANCELLED)`、`source(VARCHAR16 PC/APP/MINI/SCAN)`、`remark`、`operator_id`、`operator_name`、`create_time`、`in_time(DATETIME)`、`update_time`。
- **主键/索引**：PK `id`；UK `uk_in_order_no`；`idx_in_supplier`、`idx_in_status`、`idx_in_time`。
- **关系**：`supplier_id`→`base_supplier`；`warehouse_id`→`base_warehouse`；1:N `psi_stock_in_item`、`psi_stock_in_log`。

### 6.2 `psi_stock_in_item` 进货单明细

- **字段**：`id(PK)`、`order_id`、`book_id`、`book_name(VARCHAR255快照)`、`isbn(VARCHAR32快照)`、`quantity(DECIMAL14,3)`、`price(DECIMAL14,2)`、`amount(DECIMAL14,2)`、`batch_no(VARCHAR64)`、`remark`。
- **主键/索引**：PK `id`；`idx_in_item_order(order_id)`、`idx_in_item_book(book_id)`。
- **关系**：属 `psi_stock_in_order`（组合）；`book_id`→`base_book`。

### 6.3 `psi_stock_in_log` 进货单操作流水

- **字段**：`id(PK)`、`order_id`、`action(VARCHAR32 CREATE/SUBMIT/INSTOCK/CANCEL)`、`operator_id`、`operator_name`、`remark`、`create_time`。
- **主键/索引**：PK `id`；`idx_in_log_order(order_id)`。
- **关系**：属 `psi_stock_in_order`。

## 7. 出货域（2 张）

### 7.1 `psi_stock_out_order` 出货单（销售单）

- **字段**：`id(PK)`、`order_no(VARCHAR64,UK,SO前缀)`、`customer_id(BIGINT可空)`、`warehouse_id`、`total_qty`、`total_amount(DECIMAL14,2应收)`、`discount`、`pay_amount(DECIMAL14,2实收)`、`payment_type(VARCHAR32 CASH/WECHAT/ALIPAY/CARD/CREDIT)`、`status(VARCHAR16 DRAFT/SUBMITTED/OUTSTOCK/CANCELLED)`、`source`、`remark`、`operator_id`、`operator_name`、`create_time`、`out_time`、`update_time`。
- **主键/索引**：PK `id`；UK `uk_out_order_no`；`idx_out_customer`、`idx_out_status`、`idx_out_time`。
- **关系**：`customer_id`→`base_customer`；`warehouse_id`→`base_warehouse`；1:N `psi_stock_out_item`。

### 7.2 `psi_stock_out_item` 出货单明细

- **字段**：`id(PK)`、`order_id`、`book_id`、`book_name(快照)`、`isbn(快照)`、`quantity`、`price(DECIMAL14,2)`、`amount(DECIMAL14,2)`、`cost_price(DECIMAL14,2出库成本)`、`remark`。
- **主键/索引**：PK `id`；`idx_out_item_order(order_id)`、`idx_out_item_book(book_id)`。
- **关系**：属 `psi_stock_out_order`；`book_id`→`base_book`。

## 9. 调拨与退货域（4 张）

### 9.1 `psi_stock_transfer_order` 库存调拨单

- **字段**：`id(PK)`、`transfer_no(VARCHAR64,UK,TR前缀)`、`from_warehouse(BIGINT)`、`to_warehouse(BIGINT)`、`total_qty`、`status(VARCHAR16 DRAFT/PENDING/TRANSFERRED/CANCELLED)`、`remark`、`operator_id`、`operator_name`、`create_time`、`transfer_time`。
- **主键/索引**：PK `id`；UK `uk_transfer_no`。
- **关系**：`from_warehouse/to_warehouse`→`base_warehouse`；1:N `psi_stock_transfer_item`。

### 9.2 `psi_stock_transfer_item` 调拨单明细

- **字段**：`id(PK)`、`order_id`、`book_id`、`book_name(快照)`、`isbn(快照)`、`quantity`。
- **主键/索引**：PK `id`；`idx_transfer_item_order(order_id)`。
- **关系**：属 `psi_stock_transfer_order`；`book_id`→`base_book`。

### 9.3 `psi_return_order` 退货单（采购退货/销售退货）

- **字段**：`id(PK)`、`return_no(VARCHAR64,UK,RT前缀)`、`return_type(VARCHAR16 PURCHASE/SALES)`、`partner_id(BIGINT供应商/客户)`、`partner_name(VARCHAR128)`、`warehouse_id`、`total_qty`、`total_amount`、`status(VARCHAR16 DRAFT/FINISHED/CANCELLED)`、`reason(VARCHAR255)`、`operator_id`、`operator_name`、`create_time`、`finish_time`。
- **主键/索引**：PK `id`；UK `uk_return_no`；`idx_return_type`。
- **关系**：`partner_id` 依 `return_type` 指向 `base_supplier` 或 `base_customer`；`warehouse_id`→`base_warehouse`；1:N `psi_return_item`。

### 9.4 `psi_return_item` 退货单明细

- **字段**：`id(PK)`、`order_id`、`book_id`、`book_name(快照)`、`isbn(快照)`、`quantity`、`price(DECIMAL14,2)`、`amount(DECIMAL14,2)`。
- **主键/索引**：PK `id`；`idx_return_item_order(order_id)`。
- **关系**：属 `psi_return_order`；`book_id`→`base_book`。

## 10. 库存流水域（1 张）

### 10.1 `psi_stock_flow` 库存变动流水

- **用途**：所有出入库动作的统一台账，报表与追溯核心。
- **字段**：`id(PK)`、`biz_type(VARCHAR32 IN采购入库/OUT销售出库/CHECK盘点调整/TRANSFER_IN调拨入/TRANSFER_OUT调拨出/RET_PUR采购退货/RET_SAL销售退货/INIT期初)`、`biz_no(VARCHAR64)`、`book_id`、`warehouse_id`、`direction(TINYINT 1入库 -1出库)`、`quantity(DECIMAL14,3绝对值)`、`before_qty(DECIMAL14,3)`、`after_qty(DECIMAL14,3)`、`unit_cost(DECIMAL14,4)`、`operator_id`、`operator_name`、`source`、`create_time`。
- **主键/索引**：PK `id`；`idx_flow_book`、`idx_flow_wh`、`idx_flow_time`、`idx_flow_biz(biz_type,biz_no)`。
- **关系**：`book_id`→`base_book`；`warehouse_id`→`base_warehouse`；`biz_no` 关联对应业务单据号。

## 11. 二维码/条码域（2 张）

### 11.1 `sys_qrcode` 二维码记录

- **字段**：`id(PK)`、`biz_type(VARCHAR32 BOOK/ORDER/STOCK/CHECK)`、`biz_id(VARCHAR64 如ISBN/单号)`、`qr_content(VARCHAR255)`、`qr_url(VARCHAR255)`、`scan_count(INT)`、`create_time`。
- **主键/索引**：PK `id`；`idx_qr_biz(biz_type,biz_id)`。
- **关系**：`biz_id` 逻辑关联 `base_book.isbn` 或单据号。

### 11.2 `sys_scan_log` 扫码记录

- **字段**：`id(PK)`、`code(VARCHAR128)`、`biz_type(VARCHAR32)`、`biz_id(VARCHAR64)`、`device(VARCHAR32 APP/MINI/PC)`、`user_id`、`result(VARCHAR32 SUCCESS/FAIL)`、`create_time`。
- **主键/索引**：PK `id`；`idx_scan_code`、`idx_scan_time`。
- **关系**：`user_id`→`sys_user`；与 `sys_qrcode` 逻辑关联。
